# Evidence-backed project description

**Flipkart Sentiment Analysis | TF-IDF, SVM, Logistic Regression**

- Processed 205K+ public product-review records and built a reproducible 45K unique-review benchmark with normalized-text deduplication and stratified train/validation/test partitions.
- Compared TF-IDF Logistic Regression and linear SVM pipelines, selecting by validation macro F1 and achieving 86.81% held-out accuracy and 0.702 macro F1.
- Delivered a fitted inference pipeline, CLI predictions, confusion matrix, model-feature interpretation, and documented weak-label and domain-generalization limitations.

This is a public-data benchmark against publisher-provided sentiment labels, not a deployed Flipkart system or an independently human-labeled evaluation.
